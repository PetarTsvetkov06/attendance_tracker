# attendance_tracker

This is a **console-based Attendance Tracker** written in **C** using the **CS50 library**.  
It allows you to manage students, record their attendance, and calculate attendance percentages.  
Student data is **saved to a file**, so it persists between program runs.

---

##  Features
- Add students with a unique ID and name
- Set total number of classes
- Record how many classes a student attended
- Check individual attendance percentage
- View all students
- Automatic file saving and loading (`students.txt`)
- Low attendance warning (below 75%)
